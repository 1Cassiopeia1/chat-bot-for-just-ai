VK Chat Bot - Echo Bot
📝 Описание проекта
Этот бот для ВКонтакте предназначен для работы в беседах (групповых чатах). Бот выполняет следующие функции:

Принимает входящие сообщения через Callback API

Пересылает сообщение обратно пользователю в формате "Вы сказали: <ваше сообщение>"

Поддерживает стандартные типы запросов VK Callback API (подтверждение сервера, новые сообщения)

⚙️ Технологии
Java 17

Spring Boot 3.x

VK API

Maven

Lombok

🔧 Настройка бота в ВКонтакте
Создайте сообщество ВКонтакте

В разделе "Управление" → "Работа с API":

Включите Callback API

Укажите URL вашего сервера (например, https://ваш-сервер.ру/callback)

Получите код подтверждения (confirmation code)

Сгенерируйте access token с правами: messages

Включите Long Poll API в настройках
